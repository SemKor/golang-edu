# Перечень уроков для последовательного самостоятельного выполнения.

## Getting Started
- Для знакомства с базовыми аспектами языка рекомендуется пройти интерактивный мануал от google - https://go.dev/tour/list <br>
Параллельно с этим ознакомится глубже с понятиями изложенными в мануле в книге - [Язык программирования Go](etc/Yazyk_programmirovania_Go_Alan_A_A_Donovan_Brayan_U_Kernigan.pdf).
- Для старта локальной разработки необходимо установить среду разработки - https://code.visualstudio.com/ и поставить расширение: <br>
Name: Go <br>
Id: golang.go <br>
Description: Rich Go language support for Visual Studio Code <br>
- Установить компилятор последней версии - https://go.dev/dl/ <br>
- Установить платформу для контейнеризации приложений - https://www.docker.com/products/docker-desktop/
