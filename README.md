## База данных
Частой задачей, с которой приходится столкнуться разработчику, является задача хранения данных.</br>
Как правило, для её решения разработчик выбирает СУБД, но тогда перед ним встает новая задача -
научить нашу программу "общаться" с выбранной СУБД. </br>
Для общения нам неизбежно понадобиться написать или использовать уже имеющийся "драйвер" для работы с СУБД.</br>
Для SQL-like баз данных в Golang в пакете <b>sql</b> представлен общий интерфейс, который рекомендуется
реализовать в случае написания своей реализации драйвера. </br>
В рамках данного урока мы будем использовать БД - PostgreSQL и готовую реализацию драйвера: </br>
https://github.com/jackc/pgx </br>
<br><b>Пример подключения и работы:</b></br>
1) Запустим сервер БД в контейнере командой</br>
   <b>docker run --name labs-postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=labs -p 6432:5432 -d postgres;</b></br>
2) Подключимся к контейнеру с БД так, как показано ниже.
```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/jackc/pgx/v5"
)

func main() {
	urlExample := "postgres://postgres:postgres@localhost:6432/labs"
	// Создаем соединение с сервером БД и базой labs
	conn, err := pgx.Connect(context.Background(), urlExample) 
	if err != nil {
		fmt.Fprintf(os.Stderr, "Unable to connect to database: %v\n", err)
		os.Exit(1)
	}
	// обернем в defer вызов закрытия соединения, чтобы в конце исполнения main функции в любом случае закрыть соединение
	defer conn.Close(context.Background()) 
	var name string
	var weight int64
	// пример исполнения запроса (в БД таблицу widgets надо создать заранее, чтобы в результате не получить ошибку)
	// также можно записать запрос в отдельную переменную с помощью fmt.Sprintf() и вставить её вместо запроса,
	// который написан ниже.
	err = conn.QueryRow(context.Background(), "SELECT name, weight FROM widgets WHERE id=$1", 42).Scan(&name, &weight) 
	if err != nil {
		fmt.Fprintf(os.Stderr, "QueryRow failed: %v\n", err)
		os.Exit(1)
	}

	fmt.Println(name, weight)
}
```
С момента решения использовать БД наше приложение  получает определенное состояние - версию,
совокупность всех сущностей БД, используемых приложением.</br>
Пока приложение разрабатывается, это состояние тоже
может изменяться. Могут появляться новые сущности, или обновляться уже существующие и т.п.</br>
Для корректности и совместимости работы приложения с БД мы должны следить за ее версией.
Как правило, в таком случае создается техническая таблица, которая хранит в себе информацию о том,
в какой версии сейчас находится БД.</br>
Для перехода от одной версии к другой мы пишем скрипты миграции, которые изменяют состояние БД (пакет <b>migrations</b>).</br>
<br>У каждой версии 2 скрипта миграции:
<li><b>up</b> для приведения к состоянию версии; 
<li><b>down</b> для отката к предыдущей.

<br>Обычно в проектах используются утилиты, которые умеют работать с скриптами миграции в режиме команд,
и которые сами создают техническую таблицу версий и следят за текущей версией.</br>
В примерах скриптов к этому уроку (которые лежат в этой ветке, в папке migrations)
мы следим за версией самостоятельно, инкрементируя версию прямо в скриптах.</br>
Но задачей же к этому уроку будет написание своей утилиты, которая будет исполнять команды миграции и обновлять
версии автоматически.</br>

## Файловая система
Также разработчику иногда необходимо работать с файловой системой (например, при работе с файлами миграции).</br>
В рамках данного урока мы рассмотрим то, как считать содержимое файла, и как работать с названием файла.</br>
Для работы с файловой системой в Golang существует встроенный пакет <b>os</b>, содержащий нужные для задания к лабе функции.</br>
Для начала создадим файл <b>test.txt</b> и напишем туда "Hello world!".</br>
Теперь попробуем считать и вывести в консоль информацию из созданного файла:

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	fileContent, err := os.ReadFile("test.txt")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("File content: %s", fileContent)
}
```

Также часто необходимо найти, либо проверить существование файла по названию в какой-либо директории.</br>
Для этого существует функция os.ReadDir(), с помощью которой мы можем проверить каждое название файла в директории.</br>
Например, мы создали внутри проекта директорию "tests", в которой лежат файлы "1_test.txt" и "2_test.txt"</br>
Представим, что нам необходимо вывести содержимое всех файлов, у которых в названии в начале стоит цифра 2.</br>
Пример такой программы:

```go
package main

import (
	"fmt"
	"log"
	"os"
	"strings"
)

func main() {
	files, err := os.ReadDir("./tests")
	if err != nil {
		log.Fatal(err)
	}
	for _, file := range files {
		if strings.Split(file.Name(), ".")[0] == "2" {
			fileContent, err := os.ReadFile(file.Name())
			if err != nil {
				log.Fatal(err)
			}
			fmt.Printf("File content: %s\n", fileContent)
		}
	}
}
```

Таким образом, мы можем комбинировать поиск файла и чтение его содержимого.</br>

Используя полученные знания из предыдущего урока написать программу-утилиту, которая будет выполнять команды:
<li> up - "прогнать" все скрипты миграции с текущей до последней

<li> Во время исполнения проверять наличие технической таблицы - go_migrations и создавать её в случае отсутствия.
